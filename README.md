# SIPI Falls Website 🌊🌿

This is a tourism and booking website project for SIPI Falls. It includes pages for:

- 📍 Home
- 📖 About
- 📩 Contact Form
- 🛏️ Booking System
- 💌 Newsletter Subscription

## 💻 Built With
- HTML
- CSS
- PHP
- MySQL (for backend)
- WAMP Server for local development

## 📁 Folder Structure
- `admins/` – Admin dashboard files
- `css/` – Stylesheets
- `includes/` – PHP includes (DB, footer, etc.)
- `pages/` – About and contact pages
